# Парсер каталога книг → Excel

Собирает товары с [books.toscrape.com](https://books.toscrape.com/) (учебный сайт-магазин для парсинга) и сохраняет в Excel: название, цена, наличие, рейтинг, ссылка.

Проходит по всем страницам каталога сам, можно ограничить число страниц или взять только одну категорию. Если страница не загрузилась - делает повторные попытки, между запросами небольшая пауза, чтобы не нагружать сайт.

Такой же подход подходит для любого интернет-магазина: меняются только адрес и селекторы в `parse_book`.

## Установка

Нужен Python 3.10+

```
pip install -r requirements.txt
```

## Запуск

Весь каталог (1000 книг, 50 страниц, около минуты):

```
python parser.py
```

Только первые 3 страницы:

```
python parser.py --pages 3
```

Одна категория:

```
python parser.py --list-categories
python parser.py --category Mystery --output mystery.xlsx
```

## Что получается

Файл `books.xlsx` (или указанный в `--output`) с листом "Книги":

| Название | Цена, £ | Наличие | Рейтинг | Ссылка |
|---|---|---|---|---|
| A Light in the Attic | 51.77 | Да | 3 | https://books.toscrape.com/catalogue/... |

В таблице включен фильтр и закреплена шапка, цены - числа, так что можно сразу сортировать и считать.
